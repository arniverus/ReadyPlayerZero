# Ready Player Zero

An interactive 3D literary-analysis game for Ernest Cline's *Ready Player One*.
Runs in any modern browser (Chromebook friendly) with keyboard + mouse. No install, no VR headset.

**Controls:** WASD move · mouse look (click the screen) · click or `E` interact · `H` hint (−100 pts) · `Esc` frees the mouse

**Teacher tip:** open `index.html?debug` to see the correct evidence cards outlined in green.

**Editing questions:** open `index.html` and search for `QUESTION BANK`.
